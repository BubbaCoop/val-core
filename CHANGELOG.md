# Changelog

All notable changes to `@valiify/val-core` are documented here. Format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow the
policy in README "Versioning".

Every release — including docs-only patches — changes the
`GENERATED by @valiify/val-core@x.y.z` header in consumers' generated agents,
so each consumer must rerun `npx val-init` and commit after upgrading. See
README "Releasing".

## [Unreleased]

### Added

- GitHub Actions CI (`.github/workflows/ci.yml`): `npm test`, `npm run check`,
  a tarball guard (`npm pack --dry-run` must include the bin/schema/example,
  exclude repo-only files, and emit no npm warnings), and a tag-matches-version
  assertion on `v*` tags. Verifies only; publishing stays local.
- This CHANGELOG.
- README "Releasing" section documenting the local release procedure.

### Known gaps

- `val-init --check` only fails on stale or hand-edited generated files. A
  drifted `val/tools` symlink ("relinked") or a real `val/tools` directory
  ("SKIPPED") is reported but exits 0. Fix with the next code release.

## [0.1.1] — 2026-09-07

### Changed

- `npm pkg fix` hygiene only: `bin` path normalised (`./bin/val-init.mjs` →
  `bin/val-init.mjs`) and `repository.url` in `git+https://` form. No
  template, tool, schema or skill changes; 0.1.0 and 0.1.1 install and behave
  identically.

## [0.1.0] — 2026-09-07

### Added

- Initial public release.
- Ten agent templates (`val-figma`, `val-components`, `val-context`,
  `val-build`, `val-qa`, `val-accuracy`, `extract-structure`,
  `extract-tokens`, `extract-visual`, `extract-synthesis`) and two command
  templates (`/val`, `/extract`).
- `val-init` generator with `--check`, `--dry-run` and `--config`.
- `val.config.schema.json` and `val.config.example.json`.
- Tools: `grid-diff.mjs` (tested), `screenshot.mjs`, `generate-registry.mjs`.
- Skills: `extract-methodology`, `visual-verification`, `component-mapping`.
